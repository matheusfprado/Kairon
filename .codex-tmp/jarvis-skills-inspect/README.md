# Jarvis Codex Skills Pack

Copy the `.agents` folder to the root of your Jarvis repository.

Included:
- token-guardian
- feature-slice
- bug-hunter
- tamagotchi-domain
- jarvis-command
- targeted-tests
- state-keeper

Codex repository skills live under `.agents/skills/<skill-name>/SKILL.md`.

Suggested usage examples:
- Use $token-guardian and implement the smallest fix for ...
- Use $tamagotchi-domain to add hunger decay.
- Use $jarvis-command to add an allowlisted Spotify play command.
- Use $bug-hunter to fix this stack trace.
- Use $targeted-tests to validate the last change.

Keep AGENTS.md for global project rules. Keep these skills specialized and small.
